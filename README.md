# 15 minutes, but for whom?

A free, public-good civic map. A "15-minute city" looks different for a child, a pregnant woman, an elderly person, or a newcomer. This tool draws walking isochrones per type of person, adjusted for heat, rain, slopes and broken lifts. First area: BGC (Taguig) or Komoro.

Inspired by Francesco Procacci's map (shared by Milan Janosov).
